# FNMS

Repository for my coursework in **FNMS — Foundations of Networks and Mobile
Systems** (CSCI-GA.2630). Each lab lives in its own folder with a self-contained
README explaining how to run it.

## Labs

- [lab1a](lab1a/) — Foundations and Fundamentals: a full-stack auth app
  (FastAPI + Postgres backend, static frontend) with JWT auth and argon2id
  password hashing. See [lab1a/README.md](lab1a/README.md) to run it.
- [lab1b](lab1b/) — Agentic tracker for open-source robotics foundation models,
  layered onto a separate copy of Lab 1A so both submissions can be graded
  independently. See [lab1b/README.md](lab1b/README.md) for setup, run, rerun,
  reset, and grading-verification commands.
